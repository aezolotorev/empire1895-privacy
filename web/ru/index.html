Империя 1895

Политика конфиденциальности веб-версии игры «Империя 1895: Царь»

Дата вступления в силу: 13 октября 2026 г.

Эта политика описывает обработку данных при игре в «Империю 1895: Царь» в браузере на платформе Яндекс Игры.

1. Разработчик

Разработчик игры — D one Games, индивидуальный разработчик. По вопросам о данных, которые обрабатывает разработчик, напишите на zolotorev1984@gmail.com.

2. Данные, которые хранит игра

В игре нет регистрации и аккаунтов. Игровой прогресс, настройки и выбранный язык сохраняются в локальном хранилище браузера на устройстве игрока. Разработчик не получает копию этих данных. Очистить их можно, удалив данные сайта в настройках браузера.

3. Данные платформы Яндекс Игры

Яндекс Игры (только веб-версия) — платформа обрабатывает данные по Политике конфиденциальности Яндекса. Платформа самостоятельно определяет состав, цели и сроки обработки данных в соответствии со своей политикой.

Игра не подключает SDK Яндекс Игр для передачи платформе игрового прогресса или игровых событий.

4. Сторонние сервисы

В веб-версии нет SDK Firebase и CAS, используемых Android-приложением. Если платформа показывает рекламу или применяет собственные средства аналитики, обработку связанных с этим данных выполняет Яндекс Игры по своей политике конфиденциальности.

5. Дети

Игра не предназначена для детей младше 13 лет. Обработка данных аккаунта и платформы для несовершеннолетних регулируется правилами и политикой Яндекс Игр.

6. Запросы и изменения

По вопросам о локально сохранённом игровом прогрессе можно обратиться к разработчику по адресу zolotorev1984@gmail.com. По вопросам данных аккаунта, рекламы и сервисов платформы обращайтесь к Яндекс Играм через их сайт. При изменении этой политики мы обновим дату вступления в силу.
